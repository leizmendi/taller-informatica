Crear la carpeta · Créer le dossier

  1. Clic derecho en el escritorio, en un sitio vacío. Clic droit sur le bureau, dans un endroit vide.
  2. Nuevo → Carpeta Nouveau → Dossier VerOrdenar porNuevo ▸ CarpetaAcceso directoDocumento de texto
  3. Escribe el nombre y pulsa Intro ↵ Écris le nom et appuie sur Entrée. Taller – tu apodo
  4. Doble clic para abrir tu carpeta. Dentro, crea 3 carpetas más: Double-clic pour ouvrir ton dossier. Dedans, crée 3 autres dossiers : Textos Fotos Web

Mover un archivo · Déplacer un fichier

  1. Arrastra tu archivo de la sesión 1 (tu-apodo.txt) hasta la carpeta Textos. Fais glisser ton fichier de la séance 1 dans le dossier Textos.

Guardar un archivo nuevo · Enregistrer un nouveau fichier

  1. Abre el Bloc de notas y escribe: Hoy es martes. Estoy en el taller. Ouvre le Bloc-notes et écris deux phrases.
  2. Archivo → Guardar como Fichier → Enregistrer sous NuevoAbrirGuardarGuardar como
  3. Busca tu carpeta: Escritorio → Taller → Textos. ¡Mira bien dónde estás! Cherche ton dossier : Bureau → Taller → Textos. Regarde bien où tu es !
  4. Escribe el nombre y pulsa Guardar. Écris le nom et clique sur Enregistrer. martes
  5. Cierra el Bloc de notas. Abre tu carpeta y busca martes.txt. ¿Está? Ferme le Bloc-notes. Ouvre ton dossier et cherche martes.txt. Il est là ?
