Sesión 2 · Programas y cuentas

Programas y cuentasProgrammes et comptes

En el taller, solo se instala con el monitor delante.

À l'atelier, on installe seulement avec le moniteur à côté.

Instalar · Installer

  1. Abre Microsoft Store.
  2. Busca la app.
  3. Pulsa Obtener o Instalar.

Ouvre Microsoft Store → cherche l'app → Obtenir / Installer.

Abrir · Ouvrir

  1. Pulsa la tecla ⊞ (menú Inicio).
  2. Escribe el nombre de la app.
  3. Pulsa Intro.

Touche ⊞ → écris le nom de l'app → Entrée.

Desinstalar · Désinstaller

  1. Configuración → Aplicaciones.
  2. Busca la app en la lista.
  3. ··· → Desinstalar.

Paramètres → Applications → ··· → Désinstaller.

Las cuentas del ordenador · Les comptes de l'ordinateur

Cada cuenta tiene su escritorio, sus archivos y su contraseña. Desde una cuenta no se ven los archivos de otra.

Chaque compte a son bureau, ses fichiers et son mot de passe.

Administrador · AdministrateurPuede instalar cualquier programa y cambiar todo.Peut tout installer et tout changer.
Usuario estándar · Utilisateur standardUsa el ordenador, pero no puede instalar cualquier cosa.Utilise l'ordinateur, mais ne peut pas tout installer.

Para ver las cuentas: Configuración → Cuentas.

Pour voir les comptes : Paramètres → Comptes.

Antes de irte · Avant de partir

Bloquear · Verrouiller

⊞+L

Pour une pause : il faut le mot de passe pour revenir.

Cerrar sesión · Se déconnecter

⊞ → tu nombre → Cerrar sesión

Quand tu as fini : touche ⊞ → ton nom → Se déconnecter.

Practica · Entraîne-toi

  1. Instala la app que diga el monitor.
  2. Ábrela desde el menú Inicio.
  3. Desinstálala. ¿Sigue en el menú Inicio?
  4. Mira en Configuración → Cuentas qué cuentas hay. ¿La tuya es de administrador?
  5. Bloquea la pantalla con ⊞ + L y vuelve a entrar.
