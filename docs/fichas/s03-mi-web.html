Una web por dentroUne page web vue de l’intérieur

Una página web es un archivo de texto que el navegador sabe dibujar. Une page web est un fichier texte que le navigateur dessine.

Escribe y guarda · Écris et enregistre

  1. Abre el Bloc de notas y copia esto exactamente, con tu nombre y lo que te gusta: Ouvre le Bloc-notes et copie exactement : <meta charset="utf-8"> <h1>Hola, soy ________</h1> <p>Me gusta ________.</p> < a la izquierda de la Z · > ⇧ + esa tecla · / ⇧ + 7 · = ⇧ + 0 · " ⇧ + 2
  2. Archivo → Guardar como. Busca Documentos → Taller → Web. Fichier → Enregistrer sous. Va dans Documents → Taller → Web.
  3. En Tipo, elige Todos los archivos (*.*). Escribe el nombre y pulsa Guardar: Type : « Tous les fichiers ». Écris le nom et clique sur Enregistrer : hola.html

Ábrela y cámbiala · Ouvre-la et modifie-la

  1. Doble clic en hola.html. ¿Con qué programa se abre? ______________ Double-clic sur hola.html. Avec quel programme ?
  2. Clic derecho en hola.html → Abrir con → Bloc de notas. ¿Qué ves ahora? ______________ Clic droit → Ouvrir avec → Bloc-notes. Qu’est-ce que tu vois ?
  3. En el Bloc de notas, añade al final esta línea y pulsa Archivo → Guardar: Ajoute cette ligne à la fin et enregistre : <p>Mi comida favorita es ________.</p>
  4. Vuelve al navegador y pulsa F5. ¿Sale la frase nueva? Después, en la app: Misión 4 → Comprobar. Dans le navigateur, appuie sur F5. Puis, dans l’app : Mission 4 → Vérifier.
