Mi primera web, paso a pasoMa première page web, étape par étape

  1. Abre la carpeta «Mi web» del escritorio. Ouvre le dossier « Mi web » du bureau. 📁 Mi web
  2. Doble clic en index.html: se abre en el navegador. Double clic sur index.html : il s'ouvre dans le navigateur. 🌐 Navegador
  3. Botón derecho en index.html → «Abrir con» → «Bloc de notas». Clic droit sur index.html → « Ouvrir avec » → « Bloc-notes ». 📝 Bloc de notas
  4. Pon las ventanas una al lado de la otra. Mets les fenêtres côte à côte. ⊞+← ⊞+→
  5. Busca CAMBIA y cambia solo el texto de ese sitio. Cherche CAMBIA et change seulement le texte à cet endroit. Ctrl+B Buscar
  6. Guarda en el Bloc de notas y actualiza el navegador. Enregistre dans le Bloc-notes et actualise le navigateur. Ctrl+S Guardar F5 Actualizar
